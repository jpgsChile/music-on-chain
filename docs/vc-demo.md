# VC Demo Map — Music On Chain

Cada superficie responde **una** pregunta de inversor. Sin complejidad de producto innecesaria. Todo refuerza **escalabilidad**.

| Superficie | Ruta | Pregunta | Tesis de inversión |
| --- | --- | --- | --- |
| **Landing** | `/` | ¿Qué es Music On Chain? | Protocolo de derechos. Apps encima. |
| **Protocol** | `/protocol` | ¿Por qué es infraestructura? | Núcleo compartido, no otra app. |
| **Architecture** | `/protocol#architecture` | ¿Puede escalar? | UI→SDK→Núcleo→Adaptador→Liquidación. |
| **Settlement** | `/protocol#chains` | ¿Por qué Base? | Primer riel enterprise; más rieles sin reescribir. |
| **SDK** | `/protocol#console` | ¿Pueden construir los developers? | Una API → ecosistema. |
| **Marketplace** | `/#marketplace` | ¿Puede generar ingresos? | Licencias USDC + tarifa de plataforma. |
| **Artist Portal** | `/dashboard` | ¿Cómo ganan los creadores? | Publicar → liquidar → regalías. |
| **Fan Portal** | `/fan-dashboard` | ¿Por qué vuelven los usuarios? | Propiedad + acceso + historial. |

## Navegación (pitch)

`Protocolo · Marketplace · Creadores · Usuarios · SDK`

> El Marketplace prueba tracción.
